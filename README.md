# WorkSpot - iOS App Prototype

WorkSpot is a SwiftUI-based iOS prototype designed to help users discover suitable cafés, coworking spaces and libraries for studying or working.

## Preview

![WorkSpot main screen](Screenshots/main-screen.png)

## Features

- **Map interface** — explore locations and select a place.
- **Place details** — view ratings, price levels and opening hours.
- **Category ratings** — compare noise level, comfort, Wi-Fi and power outlets.
- **Reviews** — view ratings and written feedback.
- **Favourites** — access saved places.
- **Add a place** — explore a form for submitting new locations.
- **Profile** — view account information and profile options.

## Implementation

The prototype uses SwiftUI views, state variables and reusable components to demonstrate the intended user experience.

## Current Limitations

This is an academic prototype. It does not currently include a backend, persistent database, real-time map data or a complete user authentication system.
